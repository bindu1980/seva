# Sevaa – Community Volunteer Platform (frontend only)
Open `login.html` (or `index.html`, which redirects to login). No install, no server. Data is saved in the browser's localStorage.

Demo accounts (password demo123): asha@demo.com (volunteer), ngo@demo.com (NGO), admin@demo.com (admin).
You can also register a new volunteer or NGO. New NGOs stay "pending" until the admin verifies them.

Files: css/style.css · js/data.js · storage.js · auth.js · events.js · volunteer.js · ngo.js · admin.js
